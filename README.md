## 先确认你要开的是哪一种泰拉瑞亚服

这一步比选配置重要。泰拉瑞亚的服务端不止一个版本，资源开销差别不小。

**原版/纯净服**：直接用官方的 Terraria Server（TShock 之外的原版可执行文件），没有插件系统，最大玩家数默认上限 16 人。开荒、纯生存选它最省资源。

**TShock**：第三方服务端，插件生态成熟，权限管理、领地保护、出生点保护都靠它。开公共服或跟同学长期玩，多数人会选 TShock。

**TModLoader**：模组服专用。乐趣最多，也最吃内存，mod 装得越多，对配置的要求越像 Minecraft 模组服。

雨云面板服对这三种都是"选好游戏类型直接装"，不用自己折腾下载和依赖环境。面板里还能随时重装切换服务端，前期选错了也不至于要重新买机器。

## 配置怎么选：泰拉瑞亚其实比 MC 轻

有个被反复提到的说法值得注意：泰拉瑞亚服务端对配置的要求比 Minecraft 轻很多，2 核 4G 就足够大多数朋友服用。真正需要上心的是世界文件的保存和备份，而不是 CPU 型号。

不过关于"2 核 4G 能带多少人"，能查到的说法并不一致：有教程作者说这个规格稳定支持 4 到 8 人同时在线，也有教程写 2H4G 可以稳定跑 20 人以下的服务器。差异来自几个变量——装了多少插件、世界开到多大、是不是模组服。所以别只盯着人数下单，按你的实际玩法再往上留一档更稳。

几个具体建议：

- **硬盘**：面板服默认空间不大，官方教程建议手动调高。泰拉瑞亚的世界文件（`.wld`）本身不夸张，但自动备份和插件日志会累积。
- **计费模式**：固定计费适合每天都有人上线的服；动态计费在低价基础月租上加每日 CPU 超额部分的"电费"，CPU 使用率基准值是 20%，低于这个值不算耗电。只在晚上和周末开黑的队伍，动态计费明显更划算。
- **按天付费**：面板服支持日付，没人玩的时候关机就不烧钱，学生党用这个模式试水的成本很低。
- **IP 类型**：NAT 机型是共享公网 IP，靠端口映射对外提供服务（雨云的机器可配置 15 条端口转发），泰拉瑞亚私服用这个完全够。需要独立公网 IP 要另外付费，第三方测评里出现过 200 元/个的报价，不同地区和机型会有出入，下单时以购买页为准。

## 从购买到进服：面板开服的实际步骤

面板服的流程本质上就几步，雨云控制台里的入口在"游戏云 → 购买游戏云"：

1. 服务器类型选面板（雨云面板或 MCSM 面板），游戏类型选 Terraria 泰拉瑞亚。
2. 服务端类型按需要选原版、TShock 或 TModLoader。
3. 选机型、区域、计费模式（固定/动态/日付）和配置，确认购买。
4. 在"我的游戏云"里点进面板，用系统给的面板账号密码登录。
5. 启动实例，等控制台出现启动完成的提示。
6. 复制对外地址和端口，在游戏里点"多人游戏 → 通过 IP 加入"，填地址和端口即可。

有几个细节容易卡住新手：

- 面板启动服务端时会自动下载所需文件，第一次启动耗时比后面久，别急着反复点重启。
- NAT 机型要在控制台做端口映射，映射完成后用"对外地址 : 对外端口"连接，不是用内网地址。
- TShock 默认监听 7777 端口，官方教程特意提醒不要改 `-port` 和 `-ip` 参数。

## TShock 开服几个值得提前知道的点

**启动参数可以写在启动脚本里**。在已有启动命令后面用空格追加参数即可，常用的有 `-maxplayers`（最大玩家数）、`-password`（服务器密码）、`-world`（指定世界文件，别丢 `.wld` 后缀）、`-autocreate 3`（找不到世界时新建，数字对应小/中/大世界）、`-difficulty 1`（0 经典 / 1 专家 / 2 大师 / 3 旅程）、`-language zh-Hans`（切成中文）、`-seed`（指定种子）。改完参数再启动，等控制台出现服务器启动完成的字样就说明生效了。

**上传自己的服务端时，只替换该替换的东西**。TShock 的插件和配置放在 `ServerPlugins`、`Tshock` 目录里，启动脚本和 Linux 版的可执行文件别动——它们和你的 Windows 本地环境不通用，替换之后常见的结果是服务端起不来。

**自己的账号要手动给管理员权限**。做法是在控制台输入 `/user add 角色名 密码 owner`，然后在游戏里 `/login 密码` 完成登录。出生点保护默认开着，想让队友在出生点盖房子，用 `/protectspawn` 关掉。

**存档是唯一不能重来的东西**。面板自带备份功能，但建议额外养成习惯：更新插件、换服务端版本之前，先把世界文件单独复制一份。多开几天的服务器，世界文件的价值远超过那点月租。
